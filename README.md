## Abstract

The **Online Auction & Bidding System** is a proposed Java-based project designed to
simulate an online platform where users can buy and sell items through an auction
and bidding process.

The system will allow sellers to add items for auction by providing details such as
the item name, description, starting price, and auction duration. Buyers will be able
to view available items and place bids on them.

The main purpose of this project is to develop a practical application using Java
while applying programming concepts to solve a real-world problem. The project will
be developed progressively throughout the semester as the team learns and applies
new concepts.

The system is planned to include different types of users such as buyers, sellers,
and an administrator. Further features such as bid validation, auction closing,
winner selection, and notifications may be implemented as the project progresses.

## Planned Features

### 1. User Management

The system is planned to support:

- Buyer registration.
- Seller registration.
- Admin functionality.
- Basic user information management.

### 2. Auction Management

Sellers will be able to:

- Add items for auction.
- Enter item details.
- Set a starting price.
- Set an auction duration.
- View their auction items.

### 3. Bidding System

Buyers will be able to:

- View available auction items.
- View the current highest bid.
- Place a bid.
- Increase their bid when necessary.
- View the status of an auction.

### 4. Auction Result

When an auction is completed:

- The highest valid bidder will be identified.
- The winning bid will be displayed.
- The auction will be marked as completed.

### 5. Admin

The planned admin functionality may include:

- Viewing users.
- Viewing auction items.
- Monitoring bidding activity.
- Managing auction information.
